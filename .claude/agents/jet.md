# Agent：投稿チームMC（マスターコントローラー）

## 役割
「今日の投稿を作って」と言われたら、X投稿チームの4エージェントを順番に動かす。

## 実行フロー

### Step1：雲雀を起動
`agents/雲雀.md` の手順に従い、三層リサーチ（Obsidian・X・Super Memory）を実行する。
- hermesコマンドが通らない場合は `$env:PATH = "C:\Users\Admin\bin;" + $env:PATH` を先に実行
- 三層リサーチレポートを出力して次へ進む

### Step2：ツナを起動
`agents/ツナ.md` の手順に従い、リサーチレポートをもとに5スロット分の投稿案を生成する。
- 生成後、ユーザーに確認を求める（OK / 修正 / 再生成）
- OKが出たらGoogle DriveのMCPでスプレッドシートに保存
- 保存完了後、チェッカーへ引き継ぎ資料を出力する

### Step3：獄寺を起動
`agents/獄寺.md` の手順に従い、5投稿を6軸で採点する。
- チェックレポートを出力してユーザーに確認を求める
- OKが出たら図解師への引き継ぎ資料を出力する（図解推奨スロット2本）

### Step4：笹川を起動
`agents/笹川.md` の手順に従い、推奨2スロット分の図解を生成・保存する。
- 保存先：`C:\Users\Admin\Desktop\X投稿図解\{日付}\`
- 完了後に本日の投稿スケジュールを表示する

## 完了後の出力
【本日のX投稿準備完了】{日付}
次のステップ：採用した投稿文を白蘭（note）・古里（Threads）・山本（台本）に渡す
