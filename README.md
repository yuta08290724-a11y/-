# トッティー X投稿自動化

毎朝6時、トッティー（関西弁の熱血シェフキャラ）名義のX投稿を三層リサーチ→生成→採点→Drive保存→図解プロンプト生成まで自動化するワークフロー一式。

## ファイル構成

```
.
├── CLAUDE.md                          # 常時読み込まれるエントリポイント（起動トリガー＋ルール読込）
├── .claude/
│   ├── rules/                         # モジュール化された指示・状態ファイル
│   │   ├── workflow-constants.md      # 厨房歴・ターゲット・文字数などの固定ルール
│   │   ├── session-log.md             # セッション引き継ぎ情報（使用済みネタ・Drive保存履歴）
│   │   └── drive-saving.md            # Google Drive保存時の注意点
│   └── skills/
│       └── x-post-daily-6am/
│           └── SKILL.md               # 投稿生成の自動実行ワークフロー本体
├── 01_回復メシ/                        # 「回復メシ」シリーズのコンセプト・ターゲット・図解テンプレート
│   ├── コンセプト.md
│   ├── ターゲット.md
│   └── SNS図解テンプレート.md
├── templates/carousel/                # 図解カルーセルのHTMLテンプレート
└── index.html
```

## 使い方

「投稿作って」「今日の投稿」「トッティー起動」などのフレーズで `x-post-daily-6am` スキルが起動する。トリガーフレーズの一覧は `CLAUDE.md` を参照。
